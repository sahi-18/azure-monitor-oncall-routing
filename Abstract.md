# Abstract
The project focuses on implementing an Azure-based monitoring and alerting system for effective infrastructure monitoring and on-call notification. An Azure Virtual Machine is monitored using Azure Monitor and Log Analytics. A Data Collection Rule is used to collect monitoring data from the virtual machine.
A CPU utilization alert is configured to detect when CPU usage exceeds the defined threshold. When the alert condition is triggered, an Azure Monitor Action Group sends a notification to the designated on-call team through email. This helps the team identify high CPU usage quickly and take appropriate action.
The project demonstrates how Azure monitoring, alerting, and notification services can be integrated to improve system observability and incident response.
